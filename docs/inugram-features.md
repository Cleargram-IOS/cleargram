# Inugram features → iOS portability audit

Cross-reference of inugram (Android Telegram fork) patches against the iOS Telegram-iOS
codebase (`worktree/submodules/`). Generated by auditing ~50 feature/debloat patches and
checking each against the iOS source.

Legend:
- **portable easy** — maps cleanly to an existing iOS surface, 1–4 stock files
- **portable medium** — 4–8 files, requires real integration
- **portable heavy** — large surface rewrite, avoid as first ports
- **already has** — iOS already does this natively; don't re-implement
- **N/A** — Android-only, no iOS equivalent (Material/RecyclerView/IME/etc.)

## Heavy (avoid as first ports)

| patch | notes |
| --- | --- |
| `feature/folders-display-mode` | iOS folder tabs are a different component (no `folderDisplayMode`/`tabsMode` found). Rewrites tab rendering (titles/icons-only/both), counter modes, hide-all-chats. Largest single feature. |
| `feature/two-finger-select` | iOS has no multi-touch selection. Needs a custom two-finger gesture over chat messages. |
| `feature/message-menu` | Reorder/hide context-menu items + quick-actions row + long-tap forward/reply. Touches `ChatMessageActionSheetController` deeply. |
| `feature/paranoia` | Paranoia mode: pick chats/channels to hide everywhere; all secret chats hidden too; exit by typing a custom code in chat search. Heavy. |
| `feature/passcode` | Per-account passcodes, hidden accounts, panic code, hidden settings deeplink. iOS only has device-level `AppLock`. Heavy. |
| `feature/custom-font` | Whole-app font stack: pick a user-provided TTF/OTF/TTC family as the whole-app font, optionally with fallbacks; separate monospace font. Heavy. |
| `feature/faster-file-load` | Faster downloads/uploads. Heavy. |

## Already in iOS natively (don't re-implement)

| patch | notes |
| --- | --- |
| `feature/translator` | iOS already ships a full translator: `TranslateUI` (`translateMessages`, `ChatTranslation`, `presentTranslateScreen`, `canTranslateChats`, on-device auto-detect, ignored-languages). Stock iOS is more complete than the inugram add-on. |
| `feature/ios-menu-gesture` | The inugram patch *mimics* the iOS menu gesture on Android. iOS natively has it. |
| `feature/multi-account` | iOS already supports multiple accounts; the "raise cap / disable premium gating" part is portable (medium) but the multi-account capability itself exists. |

## Notable "FEATURES.md mentions but no dedicated patch"

- **"compact edited indicator"** (pencil icon instead of the "edited" label): listed in
  `FEATURES.md` line 76 but **no dedicated patch in `series`**. iOS already has
  `EditedMessageAttribute` + the `Conversation_MessageEditedLabel` string (rendered in
  `ChatMessageDateAndStatusNode`); if implemented it would be **portable easy** (swap the
  label for a pencil glyph in the date/status node).
